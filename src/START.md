# ⚡ START - Comandos Rápidos

## Executar em 3 Comandos

```bash
pip install -r requirements.txt
./run_dev.sh
# Abra http://localhost:5000
```

## Windows

```bash
pip install -r requirements.txt
run_dev.bat
```

## Manual (2 terminais)

```bash
# Terminal 1 - Python
python inference_server.py

# Terminal 2 - Frontend (se necessário)
npm run dev
```

---

## Funcionou? ✅

Você deve ver:
1. Site solicita permissão de câmera
2. Você clica "Permitir"
3. Você clica "Iniciar Sistema"
4. Objetos detectados aparecem com boxes coloridas
