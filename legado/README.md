# TCC Testes
Repositório para testes do projeto CyberReciclagem. Esse projeto é o trabalho de conclusão de curso para a Engenharia de Computação da Escola Politécnica, Universidade de São Paulo.

> Esta é a versão preliminar do TCC, mantida como histórico. A versão final, base do desenvolvimento atual, está na raiz do repositório (veja o [README principal](../README.md)). Problemas conhecidos desta versão e observações sobre a monografia estão em [`PROBLEMAS.md`](PROBLEMAS.md).
