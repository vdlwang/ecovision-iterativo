# TCC Testes
Repositório para testes do projeto CyberReciclagem. Esse projeto é o trabalho de conclusão de curso para a Engenharia de Computação da Escola Politécnica, Universidade de São Paulo.

> Esta é a versão iterativa, mantida como histórico. O sistema final está na raiz do repositório (veja o [README principal](../README.md)). Problemas conhecidos desta versão e observações sobre a monografia estão em [`PROBLEMAS.md`](PROBLEMAS.md).
