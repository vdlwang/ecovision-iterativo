# TCC Testes
Repositório para testes do projeto CyberReciclagem. Esse projeto é o trabalho de conclusão de curso para a Engenharia de Computação da Escola Politécnica, Universidade de São Paulo.

> Esta é a versão preliminar do TCC, mantida como histórico. A versão final, base do desenvolvimento atual, está na raiz do repositório (veja o [README principal](../README.md)). A análise original dos problemas desta versão e da monografia está no histórico (`git show 7007a0e:PROBLEMAS.md`); o [`PROBLEMAS.md`](../PROBLEMAS.md) atual guarda só o que ainda vale, como o vazamento de dados no fine-tuning.
